# 完成 Issue 125 助手归档

## Goal

允许归档和恢复助手，在隐藏不常用助手的同时完整保留配置、对话和记忆。

## Requirements

1. `Assistant` 增加向后兼容的持久化归档状态；复制助手默认未归档，备份保留状态。
2. 归档/恢复只更新助手生命周期，不调用删除或级联清理。
3. 主列表、Picker、侧栏等活跃入口排除归档助手，并提供独立归档视图与恢复操作。
4. 归档当前助手时切换到其他活跃助手；禁止操作导致零个活跃助手。
5. 归档助手仍可从归档视图进入详情并永久删除，文案与会话归档明确区分。

## Acceptance Criteria

- [ ] 归档后所有活跃选择入口隐藏，重启后保持；恢复后重新出现。
- [ ] 配置、会话、记忆无删除且恢复后可继续使用。
- [ ] 当前助手归档回退稳定，最后一个活跃助手不能被归档并有反馈。
- [ ] JSON 往返、过滤、回退与删除差异有测试；字符串已本地化。

## Notes

- 产品策略采用“允许归档默认助手，但禁止归档最后一个活跃助手”。
