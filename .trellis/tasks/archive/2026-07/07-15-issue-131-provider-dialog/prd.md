# Issue #131 修复移动端提供商弹窗布局

## Goal

确保移动端“添加提供商”弹窗在小屏和长表单内容下保持可滚动、无重叠且操作区始终可用，并完成现有修复的正式验证与 issue 交付。

## Requirements

- 弹窗高度受屏幕可用高度约束，不撑出移动端可视区域。
- 标题区和底部取消/添加操作区固定，中间表单独立垂直滚动。
- `Response API` 等较长标签为 Switch 保留稳定空间，不出现挤压、错位或重叠。
- 核对提交 `31570c1e` 的实现是否完整覆盖 issue，发现缺口时只做必要局部修复。
- 验证添加提供商的核心交互未回归，包括滚动、开关点击、取消和确认入口。

## Acceptance Criteria

- [ ] 小屏设备上弹窗未超出可视区域，标题和底部操作始终可操作。
- [ ] 长表单可在中间区域滚动到全部字段，滚动不移动固定操作区。
- [ ] `Enable`、`Response API`、`Include history reasoning` 等开关行无文字/控件重叠。
- [ ] 相关 Kotlin 编译通过，`git diff --check` 通过。
- [ ] 可用设备上完成 Debug 安装和针对性人工验收；若设备不可用则如实记录。
- [ ] issue 评论包含实际提交、验证、定位和已知边界的中英文版本，复读确认后关闭。

## Notes
