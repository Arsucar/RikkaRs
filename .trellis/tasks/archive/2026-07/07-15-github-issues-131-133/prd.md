# 处理 GitHub Issues #131-#133

## Goal

完成本轮处理期间出现的全部 open GitHub issue（#131、#132、#133、#134），在 `release/rikka-arsucar` 上形成可验证、可提交、可安装的交付，并按仓库规范逐条发布中英文交付评论后关闭 issue。

## Requirements

- #131：核实现有提供商弹窗布局修复，补足必要改动与移动端验收。
- #132：实现全局会话标签词表、关系模型、筛选、管理 UI、迁移与测试。
- #133：在 #132 原子标签 API 基础上实现助手级多 Hook 系统、严格执行状态机与审计 UI。
- #134：恢复上游普通聊天文件入口的文档 MIME/扩展名白名单与不支持类型提示。
- 严格按依赖顺序完成：#131 → #132 → #133；#134 作为后续独立小修完成；#133 不重复实现标签基础设施。
- 每个子任务独立规划、实现、检查、提交和归档；父任务负责跨 issue 回归与最终集成。
- app 模块功能改动完成后执行设备检测，并在可用设备上运行 `:app:installDebug`。
- 关闭每个 issue 前发布事实一致的独立中文与英文评论，写明分支、提交、版本（若已发布）、验证结果、定位和已知边界。
- 保留用户现有未提交修改，不纳入无关提交。

## Acceptance Criteria

- [ ] #131、#132、#133、#134 各自验收条件全部通过，相关回归无已知阻断问题。

- [ ] 每个 issue 都有对应真实实现与验证证据的中文评论和独立英文评论。
- [ ] 评论复读确认后关闭全部四个 issue。
